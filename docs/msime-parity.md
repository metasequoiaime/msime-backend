# `../msime` 与 Backend 接口对照

本次对照以 `../msime/shared/backend/`、`../msime/crates/client-core/` 和桌面端调用为准，并逐项核对 `internal/account/http.go`、`internal/server/server.go` 的实际注册路由及现有 HTTP 契约测试。

## 结论

`../msime` 当前使用的客户端接口在 Backend 均已注册，没有发现客户端正在调用但后端完全缺失的 `/v1` 路由。覆盖范围包括：

- 认证：providers、challenge、login、refresh、logout、用户资料和账号删除；
- 社区：皮肤、共享词库、回复模板的列表、详情、发布、删除、下载、收藏、评分和应用；
- 个人词库：四种词库的分页查询、目录查询、增删改、批量导入、汉字注音导入、TSV 导出和变更游标；
- 个性化数据：候选调频、候选删除、固定位置、快照导出/恢复、剪贴板和设置同步；
- 上游能力：输入法 Engine、模型目录、Chat、翻译、语音转写、流式转写、皮肤生成任务。

## 本次补强

- Admin 总览趋势增加真实服务端 `days=7|30` 查询，响应带 `range_days`，避免前端固定查询 30 天后截取；
- Admin 社区词库和回复列表增加 `updated_at`；
- Admin 总览统计卡片和次级统计增加到对应列表的跳转；
- 新增只读 `GET /api/system` 和系统状态页面，展示版本、Engine、资源以及上游能力是否配置，不返回密钥或上游地址；
- 操作日志增加 `action` 精确筛选和 `actor` 模糊筛选；
- 修复 `revoke_sessions` 对不存在用户返回成功并写审计的问题，现在不存在用户返回 404，已有用户无会话时仍保持幂等成功；
- Admin 前端构建产物、鉴权覆盖测试、筛选测试和文档同步更新。

## 不应凭空新增的接口

客户端当前没有调用“上传私人词库/剪贴板内容到管理员后台”、远程配置下发、月度成本额度或下载源回填接口。现有 Backend 对私人数据采取用户隔离，Admin 也不展示私人词条和剪贴板正文；若产品要增加这些能力，需要先确定隐私、授权、保留周期和权限模型，不能仅为了看起来功能齐全而开放。
